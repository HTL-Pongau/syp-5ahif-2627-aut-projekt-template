# SYP 5AHIF 2026/27 — AUT-Projekt Template (Classmoji)

Das ist dein persönliches Projekt-Repo für das **AUT-Projekt (Raspberry Pi + Ansible)**.
Classmoji hat es beim Veröffentlichen aus dem Template
`syp-5ahif-2627-aut-projekt-template` für dich erzeugt.

## Inhalt dieses Repos

- `02_AUT_Projekt/00_Projektauftrag.md` — der Projektauftrag (lies das zuerst!)
- `02_AUT_Projekt/01_Beurteilungskriterien.md` — so wird bewertet (K1–K6)
- `02_AUT_Projekt/02_KI_Nutzungsprotokoll.md` — Vorlage für dein Track-Artefakt
  (Track B: KI-Protokoll · Track A: Entscheidungs-/Troubleshooting-Log)

## Deine Aufgabe

1. Lies den Projektauftrag und wähle einen **Track** (A ohne KI / B mit KI).
2. Lege dein **Ansible-Projekt** in diesem Repo an (Zielstruktur siehe Projektauftrag
   Abschnitt 3 — z. B. im Ordner `ansible/` oder direkt im Repo-Root).
3. Fülle die Vorlage `02_AUT_Projekt/02_KI_Nutzungsprotokoll.md` aus.
4. Committen und pushen:
   ```bash
   git add -A
   git commit -m "AUT-Projekt: <stand>"
   git push
   ```
5. **Fertig — der letzte Push vor der Frist ist die Abgabe**
   (KW51 Di 15.12.2026, 23:59 Uhr). Du kannst also mehrmals pushen.

## Hinweise

- `.obsidian/` (Editor-Einstellungen) und `.trash/` werden nicht mitversioniert
  (siehe `.gitignore`) — nur die Markdown-Inhalte zählen.
- Frist und Status siehst du in Classmoji unter **Assignments**.
- Klappt der Push nicht: GitHub-Einladung zur Kurs-Organisation angenommen?
  `git remote -v` prüfen — es muss auf dein von Classmoji erzeugtes Repo zeigen.
